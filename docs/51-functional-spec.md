# 기능 명세서 (Functional Specification - FN-ID Matrix)

## 1. 문서 정보

### 1.1 문서 개요
본 문서는 항공사 객실 승무원의 스케줄링, 자격 관리 및 정산 프로세스를 자동화하는 `saas-crew` 시스템의 기능적 요구사항을 정의한다. 본 시스템은 복잡한 비행 스케줄의 효율적 배분과 법적 휴식 시간 준수, 그리고 비행 수당의 정확한 정산을 목적으로 한다.

### 1.2 변경 이력
| 버전 | 날짜 | 수정 내용 | 작성자 | 승인자 |
| :--- | :--- | :--- | :--- | :--- |
| v1.0 | 2024-05-22 | 초기 기능 명세서 작성 (FN-ID 50종 정의) | 시스템 설계자 | 프로젝트 매니저 |

### 1.3 관련 문서
- 시스템 아키텍처 설계서 (SA-CREW-01)
- 데이터베이스 ERD (DB-CREW-01)
- RBAC 권한 정의서 (AUTH-CREW-01)

## 2. FN-ID 체계

본 프로젝트는 기능의 추적성과 유지보수성을 위해 다음과 같은 표준 FN-ID 체계를 적용한다.

### 2.1 ID 명명 규칙
- **형식**: `FN-{도메인}-{번호}`
- **도메인 정의**:
    - `AUTH`: 인증, 권한 및 계정 관리
    - `SCHD`: 스케줄 생성, 배정 및 변경 관리
    - `QUAL`: 승무원 자격, 교육 및 인증 관리
    - `SETL`: 비행 수당 계산, 정산 및 지급 관리
    - `COMM`: 알림, 신청 및 커뮤니케이션
    - `SYS`: 시스템 설정, 로그 및 관리자 도구

### 2.2 권한 매핑 (RBAC)
- **G**: Guest (미인증 사용자)
- **CA**: Crew Assistant (보조 관리자)
- **SC**: Staff Crew (일반 승무원)
- **QM**: Qualification Manager (자격 관리자)
- **PA**: Payroll Admin (정산 관리자)
- **SA**: System Admin (시스템 관리자)

## 4. 기능별 상세 (입력/출력/처리)

### 4.1 핵심 기능 상세 분석

#### [FN-SCHD-05] 법적 휴식시간 검증
- **입력**: 승무원 ID, 배정 예정 비행 스케줄(시작/종료 시간), 항공법 기준 휴식 시간(예: 12시간)
- **출력**: 검증 결과(Pass/Fail), 위반 시간(분), 경고 메시지
- **처리 로직**:
    1. 해당 승무원의 이전 비행 종료 시간($T_{end\_prev}$)을 조회한다.
    2. 배정 예정 비행의 시작 시간($T_{start\_next}$)과의 차이를 계산한다.
    3. $\Delta T = T_{start\_next} - T_{end\_prev}$ 가 기준 휴식 시간보다 작은지 확인한다.
    4. 위반 시 `Range Types`를 활용하여 충돌 구간을 식별하고 에러를 반환한다.

#### [FN-SETL-02] 자동 수당 계산
- **입력**: 승무원 ID, 대상 월, 확정된 비행 스케줄 리스트, 수당 단가 테이블
- **출력**: 총 지급액, 항목별 수당 상세 리스트
- **처리 로직**:
    1. 해당 월의 확정된 모든 비행 레코드를 추출한다.
    2. 각 비행의 `비행시간 * 노선별 단가`를 계산하여 합산한다.
    3. 야간 비행, 장거리 비행 등 가산 수당 조건을 체크하여 추가 금액을 산출한다.
    4. Drizzle ORM의 트랜잭션을 통해 정산 임시 테이블에 저장한다.

#### [FN-SCHD-03] 승무원 자동 배정
- **입력**: 비행 노선 요구 자격(기종, 언어, 직급), 가용 승무원 풀
- **출력**: 최적 배정 리스트, 미배정 노선 목록
- **처리 로직**:
    1. 노선별 필수 자격(Qualification)을 필터링하여 후보군을 생성한다.
    2. 후보군 중 월간 누적 비행 시간이 가장 적은 순으로 정렬한다.
    3. `FN-SCHD-05` 휴식 시간 검증 로직을 통과하는지 확인한다.
    4. 최적 인원을 배정하고 배정 상태를 `Pending`으로 업데이트한다
