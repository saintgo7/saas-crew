# UI 화면 명세서 (UI Specification)

## 1. 문서 정보

### 1.1 문서 개요
본 문서는 `saas-crew` 프로젝트의 사용자 인터페이스(UI) 설계 및 화면 간의 상호작용을 정의한다. 항공사 객실 승무원의 복잡한 스케줄링, 자격 검증, 정산 프로세스를 효율적으로 처리하기 위한 화면 구조를 명시하며, RBAC(Role-Based Access Control)에 따른 접근 권한을 정의한다.

### 1.2 변경 이력
| 버전 | 작성일 | 작성자 | 변경 내용 | 승인 |
| :--- | :--- | :--- | :--- | :--- |
| v1.0 | 2024-05-22 | 시스템 설계자 | 초기 UI 화면 명세 작성 | - |

### 1.3 용어 정의
- **G (General)**: 일반 사용자/관리자 공통 권한
- **CA (Cabin Attendant)**: 객실 승무원 (개인 스케줄 및 정산 조회)
- **SC (Scheduler)**: 스케줄링 매니저 (비행 배정 및 확정)
- **QM (Qualification Manager)**: 자격 관리자 (자격 갱신 및 검증)
- **PA (Payroll Admin)**: 정산 관리자 (수당 계산 및 지급 승인)
- **SA (System Admin)**: 시스템 전체 설정 및 계정 관리

## 3. 화면별 상세

### 3.1 SC-200: 통합 스케줄 캘린더
- **목적**: North Star Metric인 '스케줄 확정 소요 시간' 단축을 위한 핵심 화면.
- **UI 구성**:
    - **상단**: 기간 선택기(Month/Week), 필터(기재별, 직급별), 검색창.
    - **중앙**: FullCalendar 기반의 그리드 뷰. 행(승무원), 열(날짜).
    - **우측**: 선택된 비행 구간의 상세 정보 패널.
- **주요 인터랙션**:
    - (SC) 승무원 간 비행 일정 드래그 앤 드롭 시 실시간 자격 검증(Validation) 팝업 노출.
    - (CA) 본인의 일정 클릭 시 비행 브리핑 노트 팝업 출력.
- **데이터 바인딩**: TanStack Query를 통한 서버 사이드 캐싱 적용으로 대규모 데이터 렌더링 최적화.

### 3.2 SC-300: 승무원 자격 관리
- **목적**: 비행 투입 가능 여부를 결정하는 자격(Certification)의 무결성 유지.
- **UI 구성**:
    - **상단**: 자격 만료 임박자 필터, 갱신 요청 대기 목록.
    - **중앙**: 데이터 테이블 (승무원명, 자격 항목, 취득일, 만료일, 상태).
    - **하단**: 페이지네이션 및 엑셀 내보내기 버튼.
- **주요 인터랙션**:
    - 자격 만료 30일 전 상태 표시줄 색상 변경 (Yellow $\rightarrow$ Red).
    - 증빙 서류 업로드 시 Cloudflare R2 스토리지로 즉시 전송.

### 3.3 SC-401: 정산 상세 및 PDF 출력
- **목적**: 투명한 수당 계산 내역 제공 및 증빙 문서 생성.
- **UI 구성**:
    - **좌측**: 비행 시간별 수당 계산식 (기본급 + 체류비 + 특수수당).
    - **우측**: 최종 지급액 및 토스페이먼츠 지급 상태 표시.
    - **상단**: 'PDF 명세서 생성' 버튼.
- **주요 인터랙션**:
    - PDF 생성 버튼 클릭 시 BullMQ 큐에 작업 추가 $\rightarrow$ Puppeteer가 서버 사이드에서 렌더링 $\rightarrow$ 완료 후 알림 전송.

## 4. 화면 흐름도

### 4.1 스케줄 확정 프로세스 (SC Persona)
`SC-100 (대시보드)` $\rightarrow$ `SC-200 (캘린더)` $\rightarrow$ `SC-201 (상세 수정)` $\rightarrow$ `자격 검증 팝업` $\rightarrow$ `SC-200 (확정 저장)` $\rightarrow$ `SC-100 (반영 확인)`

### 4.2 정산 확인 및 수령 프로세스 (CA Persona)
`SC-100 (대시보드)` $\rightarrow$ `SC-400 (정산 목록)` $\rightarrow$ `SC-401 (상세 내역)` $\rightarrow$ `PDF 다운로드` $\rightarrow$ `지급 완료 알림 확인`

## 6. 반응형

### 6.1 브레이크포인트 (Tailwind CSS 기준)
- **Mobile (sm: 640px 미만)**:
    - `SC-100`, `SC-400` 중심의 단순 리스트 뷰 제공.
    - 사이드바 $\rightarrow$ 햄버거 메뉴로 전환.
    - 캘린더 뷰 $\rightarrow$ 리스트 형태의 '내 일정' 뷰로 강제 전환.
- **Tablet (md: 768px ~ 1023px)**:
    - `SC-200` 캘린더의 일부 열 숨김 처리 및 가로 스크롤 적용.
    - 데이터 테이블의 비핵심 컬럼(비고, 생성일 등) 숨김.
- **Desktop (lg: 1024px 이상)**:
    - 모든 기능의 풀 레이아웃 제공.
    - 다중 패널(Multi-pane) 구조를 통한 데이터 입력 및 조회 동시 수행.

### 6.2 최적화 전략
- **Next.js App Router**: 서버 컴포넌트를 활용하여 초기 로딩 속도를 개선하고, 인터랙션이 필요한 부분(캘린더, 필터)만 클라이언트 컴포넌트로 분리하여 TBT(Total Blocking Time) 최소화.
- **shadcn/ui**: 일관된 디자인 시스템을 적용하여 화면 간 시각적 인지 부하를 줄임.
